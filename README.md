# Anantam Resort Website

Premium luxury resort website for **Anantam Resort, Shamshabad, Hyderabad**.

## Stack

- Next.js (App Router)
- React
- JavaScript (no TypeScript)
- Tailwind CSS
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — start production server

## Content notes

- Official logo assets live in `public/logo-full.png` and `public/logo-mark.png`.
- Image URLs are centralized in `data/images.js` / `data/gallery.js`.
- Phone, email and social links are omitted until verified (`data/site.js`).
- Accommodation categories use generic labels (Rooms / Private Cottages) until official naming is confirmed.
